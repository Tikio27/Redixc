# Demo de rediseño REDIXC

La demo está aislada en `demos/redesign`; el sitio existente conserva su implementación.

Desde la raíz del repositorio:

```bash
npm --prefix demos/redesign install
npm run dev:demo
```

Abre la URL que indique Vite. Usa los iconos de sol, luna y monitor después de WhatsApp para cambiar el tema.

No se publica automáticamente. Los formularios preparan consultas y no envían mensajes.
