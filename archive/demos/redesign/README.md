# REDIXC · Demo de rediseño

Hero familiar, temas claro/oscuro/sistema, imágenes de familias en comunidades rurales y seis páginas interactivas.

Desde esta carpeta: `npm install` y `npm run dev`. Desde la raíz del repositorio: `npm --prefix demos/redesign install` y `npm run dev:demo`.

No incluye backend ni envío de solicitudes. La disponibilidad y los precios requieren confirmación.
